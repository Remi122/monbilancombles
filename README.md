# Mon Bilan Combles

Landing de demande de bilan d'isolation des combles. Site statique publié avec GitHub Pages.

## Modifier la page

- Textes et sections : `index.html`
- Couleurs, typos, mise en page : `assets/css/style.css`
- Adresse du webhook Make : `assets/js/config.js`

Aperçu sur son ordinateur :

```
python3 -m http.server 8000
```

puis ouvrir http://localhost:8000

## Avec Claude Code

Le fichier `CLAUDE.md` décrit le projet, les règles du design system et la liste de ce qu'il reste à faire avant le lancement. Claude Code le lit tout seul à l'ouverture du dossier.
